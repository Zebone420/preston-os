## S4 - per-actor live verification (curl; token from 1Password)

For EACH enabled actor, from any machine (phone included):

   curl -sS "https://STAGING-DOMAIN/api/os/ssot/status" \
     -H "Authorization: Bearer ACTOR_TOKEN"

PASS per actor:
   - HTTP 200, ok:true, schema preston-ssot-status/1
   - actor.actor_id / actor_role match the row for THAT token
   - posture/goals/jobs/approvals/hermes/intake fields present
   - response contains NO token_hash and no secrets
